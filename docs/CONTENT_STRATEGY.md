## Hook formula (write it in every prompt)

> **First 2 seconds:** curiosity gap, question form, subject on screen.
> **Seconds 3-45:** reveal in 3 beats — SET UP → SURPRISE → SO WHAT.
> **Seconds 45-55:** payoff line + soft CTA.

## Metadata rules

- Title: max 60 chars, question form or "N things you didn't know…"
- Description: 1st line = full title again; 2nd line = 1-sentence teaser; then hashtags.
- Tags: `#Shorts` + 5 topical + `#DidYouKnow #FunFacts #Learn`
- Category: **27 — Education** (best CPM among safe categories).

## Thumbnail (Shorts vertical)

- Auto-picked frame 2 (right after the hook chip) — script.py's system prompt asks the model to design scene 1 as a "thumbnail-worthy hero shot".
- Optional upgrade later: A/B test 2-3 hand-picked frames using TubeBuddy.
